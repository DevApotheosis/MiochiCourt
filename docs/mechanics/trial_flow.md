# 审判流程

## 概述

审判流程是游戏的核心玩法，包含调查阶段和法庭阶段两个主要环节。

## 流程图

```
开始游戏
    │
    ▼
选择案件
    │
    ▼
调查阶段
    │
    ├─ 收集证据
    │   ├─ 文档证据
    │   ├─ 视频证据
    │   ├─ 音频证据
    │   ├─ 物证
    │   └─ 证言
    │
    ├─ 分析证据
    │   └─ 生成分析报告
    │
    ├─ 询问证人
    │   └─ 提升信任度
    │
    └─ 研究法律
        └─ 搜索和引用法律条文
    │
    ▼
进入法庭
    │
    ▼
法庭阶段
    │
    ├─ 法官开场
    │
    ├─ 提出证据
    │   └─ 获取证据分
    │
    ├─ 引用法律
    │   └─ 获取法律分
    │
    ├─ 盘问证人
    │   └─ 获取证言分
    │
    └─ 最终陈述
        │
        ▼
    双结局判定
        │
        ├─ 成功 → 被告无罪释放
        └─ 失败 → 被告有罪判决
    │
    ▼
案件完成
    │
    ▼
返回案件选择
```

## 调查阶段

### 证据收集

玩家可以收集多种类型的证据：

| 证据类型 | 说明 | 图标 |
|----------|------|------|
| document | 文档证据 | 文件图标 |
| video | 视频证据 | 视频图标 |
| audio | 音频证据 | 音频图标 |
| physical | 物证 | 物品图标 |
| testimony | 证言 | 对话图标 |

### 证据分析

分析证据可以获得详细的分析报告，揭示关键信息。

### 证人询问

通过对话选项提升证人信任度，信任度越高，获得的证言越详细。

## 法庭阶段

### 评分系统

| 分数类型 | 来源 | 最高分值 |
|----------|------|----------|
| 证据分 | 提出证据 | 15分/关键证据，5-10分/普通证据 |
| 法律分 | 引用法律 | 15分/次 |
| 证言分 | 盘问证人 | 10分/次 |

### 法官态度

法官态度范围为0-100，影响判决结果：

| 态度值 | 标签 | 说明 |
|--------|------|------|
| 80+ | ✅ 非常有利 | 判决倾向于无罪 |
| 60-79 | 😊 有利 | 较倾向于无罪 |
| 40-59 | 😐 中立 | 中立态度 |
| 20-39 | 😟 不利 | 较倾向于有罪 |
| 0-19 | ❌ 非常不利 | 判决倾向于有罪 |
