# 律师等级系统

## 概述

律师等级系统是玩家角色的成长体系，通过完成案件获得经验值，提升律师等级。

## 等级体系

### 等级列表

| 等级名称 | 经验范围 | 解锁内容 |
|----------|----------|----------|
| 实习律师 | 0-100 | 基础调查能力 |
| 初级律师 | 100-300 | 解锁分析技能 |
| 三级律师 | 300-600 | 解锁说服技能 |
| 二级律师 | 600-1000 | 解锁法律知识技能 |
| 一级律师 | 1000+ | 解锁全部技能 |

### 等级图标

| 等级 | 图标 |
|------|------|
| 实习律师 | 🌱 |
| 初级律师 | 📚 |
| 三级律师 | ⚖️ |
| 二级律师 | 🌟 |
| 一级律师 | 👑 |

## 经验值获取

### 获取途径

| 途径 | 经验值 | 说明 |
|------|--------|------|
| 收集证据 | +10 | 每收集一个证据 |
| 分析证据 | +15 | 每分析一个证据 |
| 完成案件（成功） | +50 | 基础奖励 |
| 完成案件（失败） | +25 | 基础奖励 |
| 难度加成 | +(难度×10) | 根据案件难度 |

### 经验值计算

```python
# 案件完成奖励
exp_reward = 50 if verdict == 'innocent' else 25
exp_reward += self.current_case.difficulty * 10
self.character.add_experience(exp_reward)
```

## 等级提升效果

### 技能加成

每个等级解锁新技能，技能等级影响游戏中的各项加成：

| 技能 | 效果 | 加成公式 |
|------|------|----------|
| 调查技巧 | 证据收集效率 | level × 5% |
| 说服能力 | 证人信任度获取 | level × 10% |
| 分析能力 | 证据分析速度 | level × 15% |
| 法律知识 | 法律引用效果 | level × 8% |
| 技术能力 | 技术证据处理 | level × 12% |

### 等级特权

| 等级 | 特权 |
|------|------|
| 实习律师 | 基础调查，无特权 |
| 初级律师 | 可查看案件提示 |
| 三级律师 | 可使用快速分析 |
| 二级律师 | 可使用法律建议 |
| 一级律师 | 可使用全部特权 |

在个人中心界面显示当前等级信息：

```python
rank = self.character.get_lawyer_rank()  # '三级律师'
rank_index = self.character.get_rank_index()  # 2
```

## 关键代码位置

```python
# 等级判定
def get_lawyer_rank(self):
    for rank in self.LAWYER_LEVELS:
        if rank['min_exp'] <= self.experience < rank['max_exp']:
            return rank['name']
    return self.LAWYER_LEVELS[-1]['name']
```
