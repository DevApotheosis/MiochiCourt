# 澪地审判庭 - 开发文档

## 项目简介

《澪地审判庭》是一款法庭主题的文字冒险游戏。玩家扮演律师，通过收集证据（实物、文档、音频、视频、证言），在法庭依据法律法规完成辩护或诉讼。

## 技术栈

- **语言**: Python 3.10+
- **GUI框架**: Tkinter
- **数据存储**: JSON文件

## 项目结构

```
city_qes/
├── src/                    # 源代码目录
│   ├── core/              # 核心逻辑模块
│   └── gui/               # 图形界面模块
├── data/                  # 游戏数据目录
│   ├── cases/             # 案件数据
│   ├── evidence/          # 证据数据
│   ├── laws/              # 法律数据
│   ├── dialogues/         # 对话数据
│   └── achievements/      # 成就数据
├── resources/             # 资源文件
│   └── images/            # 图片资源
├── docs/                  # 开发文档
├── tests/                 # 测试文件
└── run.py                 # 启动脚本
```

## 核心功能

1. **案件调查系统**: 收集、分析各种类型的证据
2. **法庭审判系统**: 提出证据、引用法律、盘问证人
3. **双结局判定**: 辩护/诉讼成功或失败
4. **成就系统**: 解锁各种游戏成就
5. **等级系统**: 律师等级晋升体系

## 快速开始

```bash
# 安装依赖
pip install pillow requests

# 运行游戏
python run.py
```
