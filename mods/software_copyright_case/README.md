# 软件著作权纠纷案模组

## 概述

本模组基于最高人民法院指导性案例279号——"西某工业软件有限公司诉广州沃某模具有限公司侵害计算机软件著作权纠纷案"开发。

## 案件背景

原告西某工业软件有限公司是NX系列计算机软件的著作权人，该软件广泛应用于3D设计、数字仿真检测及辅助制造领域。被告广州沃某模具有限公司未经许可，在其办公电脑上安装并商业使用了大量该软件。

案件的核心争议点：
1. 如何认定侵权软件数量
2. 如何确定赔偿数额
3. 被告妨害证据保全行为的法律后果

## 裁判要点

1. 在侵害计算机软件著作权纠纷中，软件著作权人能够举证证明被诉侵权软件与权利软件的名称、版本号、权利人信息等特有信息相同或者软件界面设计高度近似的，人民法院一般无需进行软件代码比对即可以认定两软件构成实质性相似。

2. 在侵害知识产权纠纷中，被诉侵权人以暴力、威胁或者其他方法妨害人民法院证据保全的，人民法院可以依法作出对其不利的事实推定。

## 模组数据

### 案件
- **案件ID**: case_copyright_001
- **案件名称**: 侵害计算机软件著作权纠纷案
- **难度**: 3（高）
- **关键证据**: 证据保全记录、软件版权信息截图、被告检讨书
- **关键法律**: 著作权法·复制权、著作权法·损害赔偿、民事诉讼证据规则·妨害证据保全

### 证据（5项）
1. 证据保全记录 - 法院证据保全详细记录
2. 软件版权信息截图 - 侵权软件版权信息
3. 被告检讨书 - 被告承认妨害证据保全的书面材料
4. 正版软件价格证明 - 用于计算赔偿数额
5. 被告网络下载记录 - 软件来源证明

### 法律（5条）
1. 著作权法·复制权
2. 著作权法·损害赔偿
3. 民事诉讼证据规则·妨害证据保全
4. 计算机软件保护条例·复制侵权
5. 反不正当竞争法·商业秘密

### 对话（10段）
- 陈经理（被告方）：否认侵权指控
- 李技术员（被告方）：透露软件来源信息
- 王法官：关于证据保全和法律适用的对话

## 安装方法

1. 将模组目录复制到游戏的 `mods/` 目录
2. 通过游戏模组管理界面安装模组
3. 重启游戏后即可在案件列表中看到新案件
